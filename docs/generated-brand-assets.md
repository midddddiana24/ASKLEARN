# ASKLearn generated brand assets

Generated with the built-in Image Generation tool on 2026-11-21. PNG originals were copied into the project without altering their generated transparency. These are illustrations, not screenshots of actual student materials.

| Asset | Project path | Used in |
|---|---|---|
| Original book/conversation logo | `frontend/public/brand/asklearn-mark-v1.png` | Header, footer, startup branding, authentication, browser icon |
| Original 3D study arrangement | `frontend/public/brand/asklearn-study-v1.png` | Authentication illustration, library quote, library and history empty states |
| Custom scalable study icons | `frontend/src/StudyIcons.tsx` | Navigation, study tools, activity totals, history |

The study icons use original SVG geometry generated in code, so they stay crisp at small sizes and follow both themes. They retain visible action labels. Decorative artwork uses empty alternative text; the authentication illustration has a descriptive alternative. PNG originals retain alpha; explicit display dimensions reserve space, and below-fold empty-state illustrations load lazily.

## Logo prompt

Use case: logo-brand. Create one polished original app logo mark for ASKLearn, a modern student learning workspace. A bold open book whose top-right page subtly becomes a rounded speech bubble, conveying ask + learn. Flat clean vector-like geometric silhouette, deep forest green #246B55 with a restrained mint #A5D9B9 accent, perfectly balanced, strong readable negative space at 32px, no tiny details, no text or letters, no gradients, no mockup, no border, no surrounding objects. Center the single compact mark, fill 80 percent of square frame. Transparent background with genuine alpha.

Sculpted matte surfaces, refined soft studio lighting, elegant rounded geometry, warm white paper, deep green #246B55 and pale mint #A5D9B9, restrained blue-gray accent. A cohesive attractive compact composition viewed isometrically, educational and welcoming, small natural contact shadow, generous clean edges, no words, no typography, no logos, no people, no decorative floating stars, no gradients in the background. All objects fully visible and centered in a wide 3:2 composition. Genuine transparent background so it works on both light and dark app surfaces.
