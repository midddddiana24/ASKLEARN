# ASKLearn evaluation worksheet

Record actual observations. Do not infer accuracy from passing software tests.

## Answer accuracy and citations

Use 30 questions answerable from the supplied lessons and 10 questions outside those materials. Before asking ASKLearn, record the reference answer and supporting passage/location. Use the same model/configuration and record the date. Have a reviewer check the answer and each citation separately.

## System Usability Scale (SUS)

After a student completes upload, chat/source inspection, a study tool, and an assessment, ask for agreement from 1 (strongly disagree) to 5 (strongly agree) for each standard item:

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

For odd-numbered items, subtract 1 from the response; for even-numbered items, subtract the response from 5. Sum adjusted values and multiply by 2.5. The resulting 0–100 score is not a percentage. Record sample size, mean, range, recruitment, and task/device context. Obtain consent; use participant codes instead of names.

| Participant code | Q1 | Q2 | Q3 | Q4 | Q5 | Q6 | Q7 | Q8 | Q9 | Q10 | SUS |
|---|---|---|---|---|---|---|---|---|---|---|---|

Reference: Brooke, J. (1996). SUS: A “quick and dirty” usability scale. In *Usability Evaluation in Industry*.

## Research boundaries

All findings must come from observed answers and voluntary participants. State that BM25 is keyword retrieval, long-file sampling limits coverage, scanned materials are unsupported, free-tier quotas vary, and AI output can be incorrect. Do not claim educational improvement from usability scores alone.
